## 🚀 Projetos em Destaque

### 🗺️ [Chrono Odyssey Map](https://www.chronoodyssey.com.br/)
Projeto independente de mapeamento interativo construído com uma arquitetura Full Stack completa. O sistema foi projetado para entregar alta performance e uma experiência de usuário fluida. A infraestrutura e o deploy foram totalmente configurados em uma VPS, garantindo disponibilidade e segurança contínuas.
- **Front-end:** `React`, `TypeScript`, `Tailwind CSS`
- **Back-end & Dados:** `Node.js`, `Prisma`, `PostgreSQL`
- **Infraestrutura:** `Nginx`, `Git`

### 🔄 Estouon (estouon.app.br)
Atuação essencial na revitalização e modernização do código legado desta plataforma. O trabalho foi conduzido colaborativamente através de **Metodologias Ágeis (Scrum)**, focando na refatoração, integração contínua e melhoria drástica da manutenibilidade do ecossistema.
- **Stack:** `JavaScript`, `React`, `CSS3`, `HTML5`, `Docker`, `Metodologias Ágeis (Scrum)`

### 📈 ClubeSigaFund
Plataforma robusta voltada para gestão e soluções financeiras. O foco principal foi a estruturação de fluxos complexos de processamento de dados no back-end e a criação de interações de usuário seguras e responsivas.
- **Stack:** `PHP`, `Laravel`, `PostgreSQL`, `Docker`, `Metodologias Ágeis (Scrum)`
